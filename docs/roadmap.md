# Roadmap

- **Now:** a playable momentum lesson (5 levels) with a single-file demo.
- **Next:** separate the mechanics (push, collide, tune-to-target, predict) into a small engine, with lessons loaded from JSON.
- **Then:** a second physics topic (forces, then energy), built on the same mechanics.
- **Then:** a second subject (chemistry: from atoms to molecules), to test whether the engine can be reused across subjects.
- **Later:** audio narration, more languages, an authoring tool for educators, and small learner studies.

Suggested stack when the project grows: TypeScript, React and Vite; Canvas or PixiJS; versioned JSON lessons.
