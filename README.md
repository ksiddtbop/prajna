# Prajna

**Learn by playing first, and read the explanation afterwards.**

Prajna (प्रज्ञा, "wisdom" or "insight") is a visual, game-based way to learn foundational ideas across subjects. You don't start by reading a definition. You push, predict, test and notice, and only then put a name to what you discovered.

## Try it

**Live demo:** https://ksiddtbop.github.io/prajna/

You can also open `index.html` in any browser. There is no install and no build step.

## First lesson: Momentum

There are five short levels. Each one starts with play and ends with a brief explanation.

| Level | What you do | What you discover |
|---|---|---|
| 1. The same push | Push a light cart and a heavy cart equally hard | Mass changes how a push turns into speed |
| 2. Hard to stop | Send three carts into a soft wall | How hard something is to stop depends on mass *and* speed: **p = m × v** |
| 3. Hit the target | Choose a mass and speed so a box slides into a zone, then do it again with a different mass | Different mass-and-speed pairs can carry the same momentum |
| 4. The crash | Predict the speed after two carts collide and stick together | Momentum is conserved: it is shared, not lost |
| 5. On your own | Answer a car-versus-runner question with no animation and no hints | Applying the idea to a new situation |

The levels don't depend on age. A child can play them by feel, and an older learner can follow the numbers shown on screen.

## Learning approach

**Play → notice → predict → experiment → explain → transfer.**

- You act first and read afterwards
- You see immediate visual feedback
- Failing is safe and retrying is free
- Hints are there when you ask for them
- The last level checks understanding without any support

See `docs/learning-design.md`.

## Where this goes

Momentum is the first proof of concept. The plan is a set of **reusable mechanics** (push-and-observe, predict-and-test, tune-to-target, balance) that teachers and subject experts can fill with content for physics, chemistry, mathematics, biology and computer science. A first sketch of the lesson format is in `content/physics/momentum.json`, and the roadmap is in `docs/roadmap.md`.
